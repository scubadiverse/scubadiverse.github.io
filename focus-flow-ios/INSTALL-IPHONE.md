# ProjectSavvy – install on iPhone (test build)

This is a test build of the ProjectSavvy premium app for iPhone. Apple has not
put it on the App Store yet, so you install it yourself. It takes about 5
minutes and you need a computer (Mac or Windows) with a cable.

## Download the app file
https://github.com/scubadiverse/scubadiverse.github.io/releases/download/ios-unsigned/ProjectSavvy-unsigned.ipa

Save that file (`ProjectSavvy-unsigned.ipa`) on your computer.

## Install it (free, no paid Apple account needed)
1. On the computer, download **Sideloadly** from https://sideloadly.io and install it.
2. Plug the iPhone into the computer with a cable. Unlock the phone and tap
   "Trust this computer" if it asks.
3. Open Sideloadly. Drag the `ProjectSavvy-unsigned.ipa` file onto the Sideloadly window.
4. Type your Apple ID email and password (a normal free Apple ID is fine), then click **Start**.
   Wait until it says done and the ProjectSavvy icon appears on the phone.
5. On the iPhone, go to **Settings → General → VPN & Device Management**.
   Tap your Apple ID under "Developer App", then tap **Trust**.
6. Open the **ProjectSavvy** icon on the home screen. Done.

## Good to know
- This test build works for **7 days**, then it stops opening. To use it again,
  repeat steps 3-4 (drag the file, click Start). That is Apple's rule for test
  builds, not ours. The real App Store version will not have this limit.
- If step 4 asks for an "app-specific password", turn on two-factor for the
  Apple ID and create one at https://account.apple.com (Sign-In and Security →
  App-Specific Passwords). Use that instead of the normal password.
