# Focus & Flow – install on your phone

A private, on-device time manager for pacing two projects (DiveScanner + AI Videos)
with focus blocks and water / break / rest reminders.

## Install on iPhone (Safari)
1. Open the app URL in **Safari**.
2. Tap the **Share** button (square with an up-arrow).
3. Tap **Add to Home Screen** > **Add**.
4. It now has its own icon and opens full-screen like an app.

## Install on Android (Chrome)
1. Open the app URL in **Chrome**.
2. Tap the **⋮** menu (top-right).
3. Tap **Install app** (or **Add to Home screen**).
4. It installs with its own icon and works offline.

For full offline / installable behaviour the folder must be served from a web
address (e.g. divescanner.net/focus-app/). Opening index.html straight from the
phone works too, but offline caching needs it served over https.
